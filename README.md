# 道初 更多遗物

Slay the Spire 独立遗物 Mod。

- 作者：沛孤
- Mod ID：`SpireOddities`
- 当前版本：`0.3.1`
- 内容：23 件原版风格遗物，提供简体中文和英文文本
- 依赖：ModTheSpire、BaseMod
- 不修改原版游戏文件，也不依赖 AKDsMoreRelics

## 文件位置

- `work/SpireOddities/`：可继续编辑和编译的源工程
- `outputs/SpireOddities.jar`：可放入游戏 `mods` 文件夹的成品
- `outputs/SpireOddities-source.zip`：源工程压缩包

## 安装

将 `outputs/SpireOddities.jar` 放入 Slay the Spire 的 `mods` 文件夹，并通过 ModTheSpire 启用 BaseMod 与本 Mod。
