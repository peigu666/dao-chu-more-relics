# 道初 更多遗物

**道初 更多遗物**（Dao Chu More Relics）是一个面向 **Slay the Spire / 杀戮尖塔** 的独立遗物 Mod，由 **沛孤** 制作。

搜索关键词：`Slay the Spire Mod`、`杀戮尖塔 MOD`、`Relic Mod`、`ModTheSpire`、`BaseMod`。

## 当前版本：0.3.1

本版本包含 23 件遗物：8 件普通、8 件罕见、7 件稀有。所有遗物都加入四名原版角色共用的对应遗物池，会像原版遗物一样在战斗、宝箱和其他正常奖励中自然出现。

### 本次更新内容

- 新增 23 件原创遗物，覆盖出牌、弃牌、消耗、格挡、抽牌、能量、药水、事件房和宝箱等原版玩法。
- 所有遗物均使用 `RelicType.SHARED`，铁甲战士、静默猎手、故障机器人和观者都可以使用。
- 遗物按普通、罕见、稀有分别加入原版遗物池，不修改开局遗物、角色、事件或原版卡牌。
- 提供简体中文和英文名称、描述与风味文本。
- 使用原创 128×128 遗物图标和对应轮廓图，不使用其他 Mod 素材。
- 仅依赖 ModTheSpire 与 BaseMod，不依赖 StSLib。
- 修正“紧绷的绳结”的中文描述，使其明确表示每回合第 3、6、9……张牌都会触发。
- 不修改原版游戏文件，也不修改或依赖 AKDsMoreRelics。

## Mod 玩法

这个 Mod 的目标不是加入一套新的复杂系统，而是把原版已经存在的行为组合起来，让遗物在不同牌组中提供小幅但有方向性的帮助。

- **出牌节奏**：紧绷的绳结奖励每回合持续出牌；细铜链和弯曲的铁钉分别鼓励技能接攻击、使用 0 费攻击。
- **弃牌与消耗**：裂开的封蜡、灰烬袋、涂蜡的线和灰烬王冠会让消耗牌、状态牌、诅咒牌或手动弃牌产生额外价值。
- **手牌与牌堆管理**：折扇、镇纸、发条羽和空骰盅会根据手牌数量或牌堆状态提供抽牌和能量。
- **防御与续航**：旧绷带、补丁皮革、松脱的纽扣和金线分别处理濒死、休息、回合结束手牌和一次性格挡。
- **探索与资源**：封好的信、生锈的罗盘和备用钥匙让能力牌、事件房和非 Boss 宝箱带来额外收益。
- **高风险高回报**：倒置沙漏、典藏印章和铅制砝码属于稀有遗物，效果更显著，但需要牌组或战斗节奏配合。

遗物不会改变角色的基础玩法，也不会要求玩家围绕某一件遗物强行构筑。拿到它们时，可以把它们当作原版遗物一样，根据当前牌组、路线和 Boss 选择是否调整策略。

## 安装与测试

1. 安装并启用 ModTheSpire 和 BaseMod。
2. 下载 `outputs/SpireOddities.jar`。
3. 将 JAR 放入 Slay the Spire 的 `mods` 文件夹，例如：`E:\SteamLibrary\steamapps\common\SlayTheSpire\mods`。
4. 启动 ModTheSpire，勾选 BaseMod 和“道初 更多遗物”，然后启动游戏。
5. 正常开始任意原版角色即可测试。需要快速测试时，可以使用 BaseMod 控制台按遗物 ID 获取遗物，例如 `SpireOddities:TightKnot`。

`outputs/SpireOddities-source.zip` 是源工程压缩包，适合修改源码、文本和图片；它不是直接放入 `mods` 文件夹的成品。

## 工程结构

- `work/SpireOddities/`：Java 源码、双语文本、遗物图标和轮廓图。
- `outputs/SpireOddities.jar`：可直接安装的编译成品。
- `outputs/SpireOddities-source.zip`：源工程压缩包。

## 依赖与许可说明

本 Mod 使用 ModTheSpire 和 BaseMod 提供的加载、注册和游戏接口。遗物图标为本项目原创生成资源。项目本身不包含原版游戏文件，也不分发 ModTheSpire、BaseMod 或其他第三方 Mod。
