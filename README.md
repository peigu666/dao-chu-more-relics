# 道初 更多遗物

道初 更多遗物（Dao Chu More Relics）是一个面向 Slay the Spire / 杀戮尖塔的独立遗物 Mod，由沛孤制作。

搜索关键词：Slay the Spire Mod、杀戮尖塔 MOD、Relic Mod、ModTheSpire、BaseMod。

GitHub 仓库：[peigu666/dao-chu-more-relics](https://github.com/peigu666/dao-chu-more-relics) · [版本与下载](https://github.com/peigu666/dao-chu-more-relics/releases)

## 当前版本：0.7.0

当前版本包含 163 件遗物：普通 62 件、罕见 57 件、稀有 44 件。所有遗物都加入四名原版角色共用的对应遗物池，会像原版遗物一样在战斗、宝箱和其他正常奖励中自然出现。

0.7.0 在保持 163 件遗物总数与稀有度分布不变的前提下，重做了数件玩法重复的遗物，修复调音叉，并统一未获得遗物的图鉴轮廓。本文先完整介绍当前版本的全部遗物，再按 0.3.1 至 0.7.0 的顺序说明新增和变更内容。

## Mod 玩法

遗物不会改变角色的基础玩法，也不会要求玩家围绕某一件遗物强行构筑。拿到它们时，可以把它们当作原版遗物一样，根据当前牌组、路线和 Boss 选择是否调整策略。

- 牌序与节奏：余烬别针、七结绳、红线和缝合面具奖励特定的攻击/技能/能力顺序；骨节骰、计数石、钉之合唱和风暴铃把连续出牌变成阶段性收益。
- 牌堆与状态：纠缠钩、穿线罗盘、潮汐钟、错误图鉴和衔尾环操作抽牌堆与弃牌堆；蛾翼、纸板面具、命运之线、黑潮和玻璃断头台把状态牌或诅咒变成代价或机会。
- 路线与资源：污渍地图、泥靴、埋藏钥匙、绕路王冠、油润钥匙、开槽石和命运收据分别影响事件、精英、宝箱、卡牌奖励和战斗后的金币。
- 风险收益：烛芯、脆冠、盐冠、偷来的时刻、蜘蛛交易和空白契约用生命、易伤、伤口或诅咒换取能量、抽牌和爆发；镜骰、错位罗盘、分裂硬币和也许引擎则提供不同程度的随机性。

## 安装与测试

1. 安装并启用 ModTheSpire 和 BaseMod。
2. 下载 SpireOddities-0.7.0.jar。
3. 将 JAR 放入 Slay the Spire 的 mods 文件夹，例如 E:\SteamLibrary\steamapps\common\SlayTheSpire\mods。
4. 启动 ModTheSpire，勾选 BaseMod 和“道初 更多遗物”，然后启动游戏。
5. 正常开始任意原版角色即可测试。需要快速测试时，可以使用 BaseMod 控制台按遗物 ID 获取遗物，例如 SpireOddities:TightKnot 或 SpireOddities:RedString。

SpireOddities-source-0.7.0.zip 是包含 Java 源码、双语文本和游戏运行图标的源码包，适合修改和构建；高分辨率原始美术图仍保留在 GitHub 完整仓库的 `work/SpireOddities/art-source/` 中，但不放入源码压缩包。源码包不是直接放入 mods 文件夹的成品。

## 工程结构

- work/SpireOddities/：Java 源码、双语文本、163 组遗物图标和轮廓图。
- outputs/SpireOddities.jar：本地构建成品。
- outputs/SpireOddities-source.zip：当前源工程压缩包。
