# 道初 更多遗物

**道初 更多遗物**（Dao Chu More Relics）是一个面向 **Slay the Spire / 杀戮尖塔** 的独立遗物 Mod，由 **沛孤** 制作。

搜索关键词：`Slay the Spire Mod`、`杀戮尖塔 MOD`、`Relic Mod`、`ModTheSpire`、`BaseMod`。

## 当前版本：0.6.0

本版本包含 163 件遗物：62 件普通、57 件罕见、44 件稀有。所有遗物都加入四名原版角色共用的对应遗物池，会像原版遗物一样在战斗、宝箱和其他正常奖励中自然出现。

### 本次更新内容

- 新增 23 件原创遗物，覆盖出牌、弃牌、消耗、格挡、抽牌、能量、药水、事件房和宝箱等原版玩法。
- 0.4.0 新增 40 件原创遗物，扩展格挡破碎、生命阈值、金币消费、精英房、卡牌奖励概率、姿态切换和充能球等触发点。
- 新增遗物继续使用原版已有的格挡、力量、敏捷、抽牌、能量、药水、金币和路线机制，不加入新的状态关键词。
- 新增的 40 组主图与轮廓图均为原创资源，抠除背景后以透明 128×128 RGBA PNG 入包。
- 所有遗物均使用 `RelicType.SHARED`，铁甲战士、静默猎手、故障机器人和观者都可以使用。
- 遗物按普通、罕见、稀有分别加入原版遗物池，不修改开局遗物、角色、事件或原版卡牌。
- 提供简体中文和英文名称、描述与风味文本。
- 使用原创 128×128 遗物图标和对应轮廓图，不使用其他 Mod 素材。
- 仅依赖 ModTheSpire 与 BaseMod，不依赖 StSLib。
- 0.5.0 重做 20 件重复度较高的遗物，加入牌复制、临时无色牌、保留手牌、牌堆操控、风险收益和延迟触发。
- 0.5.1 修复金线、银线和磨光石未使用当前本体格挡回调、导致效果可能不触发的问题，并校正“每 3 张牌”类遗物的中英文文本。
- 0.6.0 新增 100 件原创遗物，加入牌序、洗牌、弃牌、抽牌堆/弃牌堆、药水、金币、房间、精英、姿态、充能球、治疗和风险收益等玩法。
- 0.6.0 为新增遗物加入 100 组原创 128×128 RGBA 主图与轮廓图，并完成中英文文本、稀有度和共享遗物池注册。
- 不修改原版游戏文件，也不修改或依赖 AKDsMoreRelics。

## Mod 玩法

0.5.0 开始，重复度较高的遗物不再统一奖励格挡、抽牌或能量，而是把战斗中的牌堆和手牌变成可操作资源。它们仍然使用游戏已有的牌、药水、费用和遗物接口，不新增外部依赖。

- **牌堆操作**：紧绷的绳结降低随机手牌费用；裂开的封蜡和缝补口袋复制牌；黄铜沙漏和磨光石让洗牌、格挡转化为牌资源。
- **临时牌与弃牌**：旧火柴盒、空骰盅、穿线针和镀金剪刀会生成一次性的无色牌；涂蜡护符生成匕首；涂蜡的线把弃牌延迟转化为下回合抽牌。
- **风险收益**：铁制指环用生命换取能量，但会把伤口塞进弃牌堆；旧绷带在濒死时提供力量；裂纹镜片把状态牌和诅咒变成可以主动消耗的牌。
- **消耗与爆发**：裂开的封蜡复制被消耗的牌，灰烬王冠在连续消耗后造成范围伤害，镀金剪刀则提供一次性的稀有无色牌。
- **药水与防御转化**：塞住的药瓶让药水循环起来；金线把大量格挡转化为敏捷，银线则提供一次更大的抽牌窗口。
- **探索与资源**：封好的信、生锈的罗盘和备用钥匙让能力牌、事件房和非 Boss 宝箱带来额外收益。
- **高风险高回报**：倒置沙漏、典藏印章和铅制砝码属于稀有遗物，效果更显著，但需要牌组或战斗节奏配合。
- **0.6.0 牌序与节奏**：余烬别针、七结绳、红线和缝合面具奖励特定的攻击/技能/能力顺序；骨节骰、计数石、钉之合唱和风暴铃把连续出牌变成阶段性收益。
- **0.6.0 牌堆与状态**：纠缠钩、穿线罗盘、潮汐钟、错误图鉴和衔尾环操作抽牌堆与弃牌堆；蛾翼、纸板面具、命运之线、黑潮和玻璃断头台把状态牌或诅咒变成代价或机会。
- **0.6.0 路线与资源**：污渍地图、泥靴、埋藏钥匙、绕路王冠、油润钥匙、开槽石和命运收据分别影响事件、精英、宝箱、卡牌奖励和战斗后的金币。
- **0.6.0 风险收益**：烛芯、脆冠、盐冠、偷来的时刻、蜘蛛交易和空白契约用生命、易伤、伤口或诅咒换取能量、抽牌和爆发；镜骰、错位罗盘、分裂硬币和也许引擎则提供可控程度不同的随机性。

遗物不会改变角色的基础玩法，也不会要求玩家围绕某一件遗物强行构筑。拿到它们时，可以把它们当作原版遗物一样，根据当前牌组、路线和 Boss 选择是否调整策略。

## 安装与测试

1. 安装并启用 ModTheSpire 和 BaseMod。
2. 下载 `outputs/SpireOddities.jar`。
3. 将 JAR 放入 Slay the Spire 的 `mods` 文件夹，例如：`E:\SteamLibrary\steamapps\common\SlayTheSpire\mods`。
4. 启动 ModTheSpire，勾选 BaseMod 和“道初 更多遗物”，然后启动游戏。
5. 正常开始任意原版角色即可测试。需要快速测试时，可以使用 BaseMod 控制台按遗物 ID 获取遗物，例如 `SpireOddities:TightKnot`。

`outputs/SpireOddities-source.zip` 是源工程压缩包，适合修改源码、文本和图片；它不是直接放入 `mods` 文件夹的成品。

## 工程结构

- `work/SpireOddities/`：Java 源码、双语文本、遗物图标和轮廓图。
- `outputs/SpireOddities.jar`：可直接安装的编译成品。
- `outputs/SpireOddities-source.zip`：源工程压缩包。
