# 道初 更多遗物

独立的 Slay the Spire（杀戮尖塔）遗物 Mod，作者：沛孤。

当前版本为 0.9.0，共 163 件遗物：62 件普通、57 件罕见、40 件稀有、4 件 Boss。共用遗物池 158 件，职业池 5 件（静默猎手 1 件、故障机器人 2 件、观者 2 件）。四件 Boss 遗物均进入原版 Boss 遗物选择；其余遗物保留职业池归属。0.9.0 重做重复玩法，不改 Mod ID、遗物 ID 或图标。

本工程包含：

- `src/main/java/`：68 个 Java 源文件，包括 Mod 主类、奖励跳过补丁、通用遗物基类和 163 件遗物。
- `src/main/resources/`：简体中文/英文文本、163 组 128×128 主图和轮廓图。
- `art-source/`：高分辨率原始遗物图保留在完整 GitHub 仓库中；它们不是构建必需文件，因此不放入版本化源码压缩包。源码包包含全部可编译代码、双语文本和游戏实际使用的图标/轮廓。
- `ModTheSpire.json`：ModTheSpire 清单。

依赖 ModTheSpire 3.30.0 与 BaseMod 5.56.0，不依赖 StSLib，不修改原版游戏文件，也不修改或依赖 AKDsMoreRelics。

详细的更新内容、遗物效果、玩法说明和安装步骤请查看仓库根目录的 `README.md`。
