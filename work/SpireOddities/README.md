# 道初 更多遗物

独立的 Slay the Spire（杀戮尖塔）遗物 Mod，作者：沛孤。

当前版本为 0.6.3，共 163 件遗物：62 件普通、57 件罕见、44 件稀有。0.6.0 新增 100 件带有牌序、洗牌、弃牌、房间、金币、姿态、充能球和风险收益机制的遗物；0.6.1 重排仓库文档并缩小遗物图标主体，避免在遗物列表中互相重叠；0.6.2 隐藏无意义的内部计数器，仅保留有实际进度意义的计数显示；0.6.3 让图鉴只绘制屏幕附近的遗物，减轻滚动时的绘制开销，不改变玩法。所有遗物都注册为四名原版角色共用，并自然加入对应遗物池。

本工程包含：

- `src/main/java/`：67 个 Java 源文件，包括 Mod 主类、通用遗物基类和 163 件遗物。
- `src/main/resources/`：简体中文/英文文本、163 组 128×128 主图和轮廓图。
- `art-source/`：原始遗物源图与图标制作记录。
- `ModTheSpire.json`：ModTheSpire 清单。

依赖 ModTheSpire 3.30.0 与 BaseMod 5.56.0，不依赖 StSLib，不修改原版游戏文件，也不修改或依赖 AKDsMoreRelics。

详细的更新内容、遗物效果、玩法说明和安装步骤请查看仓库根目录的 `README.md`。
