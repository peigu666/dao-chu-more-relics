# 道初 更多遗物

独立的 Slay the Spire（杀戮尖塔）遗物 Mod，作者：沛孤。

当前版本为 0.5.1，共 63 件遗物：22 件普通、22 件罕见、19 件稀有。0.5.1 修复了三个格挡触发遗物使用错误生命周期回调的问题，并校正了计数型遗物文本。0.5.0 重做了 20 件重复度较高的遗物，加入牌复制、临时无色牌、保留手牌、牌堆操控、风险收益和延迟触发。所有遗物都注册为四名原版角色共用，并自然加入对应遗物池。

本工程包含：

- `src/main/java/`：66 个 Java 源文件，包括 Mod 主类、通用遗物基类和 63 件遗物。
- `src/main/resources/`：简体中文/英文文本、63 组 128×128 主图和轮廓图。
- `art-source/`：63 张原创遗物源图。
- `ModTheSpire.json`：ModTheSpire 清单。

依赖 ModTheSpire 3.30.0 与 BaseMod 5.56.0，不依赖 StSLib，不修改原版游戏文件，也不修改或依赖 AKDsMoreRelics。

详细的更新内容、遗物效果、玩法说明和安装步骤请查看仓库根目录的 `README.md`。
